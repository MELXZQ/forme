## 浏览器实测

使用本机内置浏览器，分别设置 **1440×900、1024×768、390×844、360×800**。这些是浏览器视口测试，并不代表真机或所有浏览器兼容性测试。

- 四种宽度均测量 `document.documentElement.scrollWidth`，没有超过视口宽度。已查看桌面和手机首屏、系列、列表、详情及人物区的代表性画面。
- 自动轮播运行时观察到不同幻灯片；手动分页、上一张/下一张、暂停入口实际操作成功。暂停按钮显示 Resume，`aria-pressed=true`。修正了文字层遮挡控制区的层叠问题。
- 桌面商品轨道按钮实际改变横向位置；轨道末尾和标题的 View all 使用正确 URL。
- 人物区向下滚动后背景到近黑、人物到位、5 个标签出现。向上滚动时测到背景进度约 0.87、人物下移约 17.4%、末尾标签恢复隐藏；继续向下自然进入 Collections。
- 手机使用独立 SVG 构图和坐标；五个标签实测高度均为 50 CSS 像素，标签之间没有矩形重叠。手链标签调整至较低位置并增加深色衬底，避免文字落在皮肤上失去对比。
- 在人物区刷新后，背景、位置和标签恢复；从手机 Necklaces 标签进入 `?category=necklaces`，显示 4 件对应商品。

## 明确未完成的实测

- 没有使用实体手机：iOS Safari、Android Chrome 的真实触摸滑动、地址栏变化、屏幕旋转尚未实机验证。代码已提供原生轨道滚动、轮播触摸处理、`svh`/`dvh` 和窗口变化处理。
- 当前浏览器控制接口未提供媒体特性模拟，因此没有实际切换 `prefers-reduced-motion: reduce`；实现包含对应 CSS 和 `matchMedia` 监听，但不能把代码检查称为运行验证。
- 没有完成 VoiceOver、所有键盘路径、所有颜色组合或跨浏览器的完整无障碍审计。已实际验证的键盘项为弹窗 Escape 关闭和焦点恢复。

- ESLint / Prettier 扩展仅列为推荐，没有操作扩展市场安装。网站运行不依赖这些扩展。
