## 需求场景对应

| 场景 | 实际验证 |
|---|---|
| 1 创建采购不加库存 | 草稿/确认只形成约定及一个义务，余额不变 |
| 2 部分付款/分批收货 | 部分现金、多包裹及逐批验收独立进度 |
| 3 跨入口重试 | 同采购/验收号不同入口和并发重试，仅一次库存影响 |
| 4 20件收到18件含1破损 | 17可售、1不可售、2待履行 |
| 5 超发/少货/退货/退款 | 拒绝超收；明确关闭少货；退供应商扣实物，退款独立；补发另验收 |
| 6 运费去重 | 已包含费用引用一个义务，独立费用另记，不随关联重复计数 |
| 7 多币种/缺汇率 | 原币分组，未知换算计数；显式汇率与日期现金流正确 |
| 8 快照不可变 | 供应商/商品修改后采购原快照保留 |
| 9 月末/闰日/任务重试 | 原始锚点无漂移，并发任务无重复周期 |
| 10 规则修改 | 不篡改已生成且已付款历史；恢复需明确日期 |
| 11 自动扣费待核实 | 无实际现金记录保持 UNVERIFIED |
| 12 迟到通知合并 | 采购/支出/包裹详情引用同一主要事项，独立差异保留 |
| 13 签收不入库 | SIGNED 不改变库存；实际验收才增加 |
| 14 多包裹 | 两包裹独立分配/进度，拒绝超分配 |
| 15 仓管隔离 | 服务与真实HTTP均拒绝成本、财务凭证、导出、循环修改 |
| 16 并发与重试 | 同付款并发只一个现金记录；最后1件竞争只一次验收；任务周期唯一 |
| 17 原功能 | 原运营/通知/阈值/商品HTTP回归通过；真实浏览器检查见下 |
| 18 重启持久性 | 数据库和应用实际重启，私有附件可读，补查无重复 |

额外边界：12期历史补建预览与重复补建、每类历史逾期汇总通知；现金实际日期与冲正日期；CSV公式转义；整数分、负数量、跨币种抵扣、超额退款、重复冲正与追加历史数据库限制；SVG伪装拒绝。
